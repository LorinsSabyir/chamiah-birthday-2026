# Memories photos

Put photos for the Memories page in this folder.

In `src/app/features/memories/memory-decks.ts`, update the `image` field of an
entry in `MEMORIES` to match its filename. For example:

```ts
image: 'images/memories/our-first-date.jpg'
```

You can also edit the card's `alt`, `title`, `caption`, and `footer` in the same entry.
