# Things I Love photos

Put photos for the Things I Love page in this folder.

In `src/app/features/things-i-love/things-i-love.data.ts`, update the `image` field of an
entry in `THINGS_I_LOVE` to match its filename. For example:

```ts
image: 'images/things-i-love/her-smile.jpg'
```

You can also edit the card's `alt`, `title`, `caption`, and `footer` in the same entry.
